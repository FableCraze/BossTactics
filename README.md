# Boss Tactics

Boss Tactics apresenta táticas de chefes e inimigos comuns em português brasileiro, com acompanhamento de instâncias, filtros por função, diário, minipainel e ferramentas de compartilhamento.

## Documentação

- [Índice completo](Docs/README.md)
- [Guia do usuário](Docs/GuiaDoUsuario.md)
- [Arquitetura e formato dos dados](Docs/Addon.md)
- [Documentação das masmorras](Docs/README.md#índice)

Use `/bosstactics` dentro do jogo para abrir o Diário de Chefes e `/bosstactics ajuda` para consultar os comandos disponíveis.
